# Machine Learning & AI Laboratory Programs — MVJ College of Engineering

> Interactive web-based code repository and copy tool containing verified Python implementations for all 10 VTU Machine Learning Laboratory exercises.

---

## 1. Project Title
**Machine Learning Lab Programs** (`Ml-lab`) — Interactive VTU / MVJ ML Laboratory Code Suite.

## 2. Project Overview
An accessible offline-first web portal providing clean, verified Python implementations of foundational machine learning algorithms. Each program is accessible via instant copy buttons with highlighted syntax and dataset explanations.

## 3. Program Index (10 Core Algorithms)
1. **Find-S Algorithm:** Implementation of maximally specific hypothesis learning for concept learning.
2. **Candidate Elimination Algorithm:** General-to-specific version space bounding with positive and negative samples.
3. **ID3 Decision Tree:** Information gain and entropy calculation for decision tree classification.
4. **Backpropagation Artificial Neural Network:** Multi-layer perceptron training with gradient descent weight updates.
5. **Naive Bayes Classifier:** Probabilistic classification based on Bayes' theorem and class priors.
6. **Bayesian Network Evaluation:** Computing conditional probability distributions from empirical sample data.
7. **K-Nearest Neighbors (KNN):** Distance-weighted local neighborhood classification.
8. **K-Means Clustering:** Unsupervised cluster centroid optimization on tabular data.
9. **Expectation Maximization (EM) Algorithm:** Gaussian Mixture Model clustering compared with K-Means.
10. **Locally Weighted Regression (LOWESS):** Non-parametric locally weighted polynomial regression fitting.

## 4. Technology Stack
- **Web App:** HTML5, CSS3, JavaScript
- **Algorithms:** Python 3, NumPy, Pandas, Scikit-Learn
